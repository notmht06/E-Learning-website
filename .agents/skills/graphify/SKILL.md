# Graphify — AST Codebase Graph & Rational Sciences Concept Graph

This skill provides two complementary capabilities:

## 1. Codebase Cross-Layer AST Intelligence (The Eye)
- **Zero-Token Dependency Mapping:**
  - Parse TypeScript and Python ASTs to trace complete call-paths:
    `Button / UI Component` ➔ `API Client` ➔ `FastAPI Route` ➔ `Service Layer` ➔ `SQLAlchemy ORM Model` ➔ `SQLite Table`.
  - Avoid scanning dozens of files into context by querying direct graph edges.

## 2. Rational Sciences Interactive Concept Graph (Product Feature)
- **Concept Graph Architecture for Dar al-Hikmah:**
  - Traditional Islamic philosophy is inherently a networked ontology.
  - Core Ontological Nodes:
    - **اصالت وجود (Primacy of Being)** ➔ connects to: *تشکیک وجود*, *بداهت وجود*, *ابطال اصالت ماهیت*, *برهان صدیقین*.
    - **تشکیک وجود (Gradation of Being)** ➔ connects to: *وحدت در عین کثرت*, *نور الانوار سهروردی*, *مراتب هستی*.
    - **حرکت جوهری (Substantial Motion)** ➔ connects to: *حدوث زمانی عالم*, *ربط حادث به قدیم*, *تکامل نفس*.
    - **اتحاد عاقل و معقول (Union of Intellect & Intelligible)** ➔ connects to: *معرفت‌شناسی صدرایی*, *مراتب ادراک*.
  - **Node Metadata Binding:**
    - Each concept node links directly to:
      1. Specific audio lecture sessions (e.g. *شرح بدایة الحکمة* sessions 2-5).
      2. Specific monographs & book chapters (e.g. *مبادی حکمت صدرایی* Chapter 1).
      3. Scholarly articles and research notes.
  - **Rendering Engine:**
    - Lightweight interactive SVG / canvas with spring physics (`motion/react` or D3-force).
    - Palette: Warm paper `#FAF8F5`, Obsidian `#0C0D0E`, Umber/Copper `#8A532B` / `#C58B43`.
