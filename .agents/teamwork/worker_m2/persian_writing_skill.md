Core Methodology:
1. Ban Bureaucratic Tells:
   - NEVER use «می‌باشد / می‌باشند» -> ALWAYS use «است / هستند».
   - NEVER use «می‌گردد / گردید» -> ALWAYS use «می‌شود / شد».
   - NEVER use «به شمار می‌رود»، «محسوب می‌شود» when «است» suffices.
2. Ban AI Cliché Openers & Triads:
   - NEVER use «لازم به ذکر است»، «شایان ذکر است»، «باید خاطرنشان کرد».
   - NEVER use «از اهمیت ویژه‌ای برخوردار است»، «نقش بسزایی ایفا می‌کند».
   - NEVER use «در دنیای امروز»، «در عصر دیجیتال»، «در نهایت می‌توان گفت».
   - NEVER use «نه تنها ... بلکه» or rule-of-three triads.
3. Orthography & Typographic Discipline:
   - Proper Persian ZWNJ (نیم‌فاصله) for «می‌شود»، «ها»، «تر/ترین»، «ای» نکره.
   - Persian digits (۰۱۲۳۴۵۶۷۸۹) in user-facing Persian text.
   - Persian quotes («گیومه») instead of straight Latin quotes (" ").
   - Correct Arabic characters: ی instead of ي, ک instead of ك.
   - Respect هکسره.
4. Scholar Identity:
   - Always strictly: «حجت الاسلام دکتر زنجیر زن حسینی».
