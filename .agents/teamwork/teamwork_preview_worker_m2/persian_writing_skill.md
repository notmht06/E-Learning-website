# Persian Writing Skill Summary for Worker M2

- Always use proper Persian ZWNJ (نیم‌فاصله) for «می‌شود»، «ها»، «تر/ترین»، «ای» نکره.
- Persian digits (۰۱۲۳۴۵۶۷۸۹) in user-facing Persian text.
- Persian quotes («گیومه») instead of straight Latin quotes (" ").
- Prohibit robotic copulas: no «می‌باشد / می‌باشند» (use «است / هستند»), no «می‌گردد / گردید» (use «می‌شود / شد»).
- Avoid bureaucratic padding: no «لازم به ذکر است»، «شایان ذکر است».
- Official Scholar Identity: «حجت الاسلام دکتر زنجیر زن حسینی».
