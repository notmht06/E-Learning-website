# Persian Writing & RTL Documents (Local Copy for spec_miner_m1_endpoints)

## Core Principles
1. Detect register before writing: Formal-but-Human (رسمی-انسانی) for academic/platform endpoints and messages.
2. Ban bureaucratic tells:
   - ❌ Never use «می‌باشد / می‌باشند» -> use «است / هستند».
   - ❌ Never use «می‌گردد / گردید» (as copula) -> use «می‌شود / شد».
   - ❌ Never use «به شمار می‌رود»، «محسوب می‌شود» when «است» suffices.
3. Ban AI clichés:
   - ❌ Never use «لازم به ذکر است»، «شایان ذکر است»، «باید خاطرنشان کرد».
   - ❌ Never use «از اهمیت ویژه‌ای برخوردار است»، «نقش بسزایی ایفا می‌کند».
   - ❌ Never use «در دنیای امروز»، «در نهایت می‌توان گفت»، «نه تنها ... بلکه».
4. Orthography & Typographic Discipline:
   - Proper ZWNJ (نیم‌فاصله) for «می‌شود»، «ها»، «تر/ترین».
   - Persian digits (۰۱۲۳۴۵۶۷۸۹) in Persian user-facing text.
   - Persian quotes («گیومه») instead of straight quotes (" ").
   - Clean characters: ی instead of ي, ک instead of ك.
5. Official scholar identity:
   - Strictly «حجت الاسلام دکتر زنجیر زن حسینی».
