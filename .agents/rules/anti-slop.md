# Anti-AI-Slop Strict Rule

When creating or modifying frontend components, you MUST NEVER introduce AI clichés:
- NEVER use background blurred ambient neon glow balls (`blur-3xl`, `bg-*-500/10`).
- NEVER use gradient clipped text (`bg-clip-text text-transparent`).
- NEVER use floating pill tags with green pulsing animated dots (`w-2 h-2 bg-emerald-500 animate-pulse`).
- NEVER use generic 3-card grids with Lucide icons inside colored square backgrounds.
- ALWAYS adhere to the bespoke design tokens in `DESIGN.md`: Deep obsidian `#0C0D0E`, warm paper `#FAF8F5`, warm umber/copper `#8A532B` / `#C58B43`, crisp 1px borders, and Dana Persian typography.
