# Persian Writing & Human Text Quality Rule (persian-writing)

When generating or modifying any user-facing Persian text, copy, metadata, course descriptions, or documentation:

1. **Ban Bureaucratic Tells (افعال و تکلف‌های اداری/رباتیک):**
   - ❌ NEVER use «می‌باشد / می‌باشند» -> ALWAYS use «است / هستند».
   - ❌ NEVER use «می‌گردد / گردید» (as copula) -> ALWAYS use «می‌شود / شد».
   - ❌ NEVER use «به شمار می‌رود»، «محسوب می‌شود» when «است» suffices.

2. **Ban AI Cliché Openers & Triads:**
   - ❌ NEVER use «لازم به ذکر است»، «شایان ذکر است»، «باید خاطرنشان کرد».
   - ❌ NEVER use «از اهمیت ویژه‌ای برخوردار است»، «نقش بسزایی ایفا می‌کند».
   - ❌ NEVER use «در دنیای امروز»، «در عصر دیجیتال»، «در نهایت می‌توان گفت».
   - ❌ NEVER use «نه تنها ... بلکه» or rule-of-three triads («سریع، آسان و مطمئن»).

3. **Orthography & Typographic Discipline:**
   - ALWAYS use proper Persian ZWNJ (نیم‌فاصله) for «می‌شود»، «ها»، «تر/ترین»، «ای» نکره.
   - ALWAYS use Persian digits (۰۱۲۳۴۵۶۷۸۹) in user-facing Persian text.
   - ALWAYS use Persian quotes («گیومه») instead of straight Latin quotes (" ").
   - Correct Arabic characters to Persian: ی instead of ي, ک instead of ك.
   - Respect هکسره: distinguish between «ـه» (است) and کسره اضافه «ـِ».

4. **Register: Formal-but-Human (رسمی اما زنده و انسانی):**
   - Direct, crisp sentences without bureaucratic padding.
   - Dignified academic voice suitable for a traditional wisdom and philosophy academy, avoiding both robotic bureaucracy and overly colloquial slang in scholarly articles.
