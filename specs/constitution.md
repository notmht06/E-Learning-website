# قانون اساسی پلتفرم رسمی حجت الاسلام دکتر زنجیر زن حسینی
## Core Project Constitution (Spec-Driven Development / Spec Kit)

این سند، بالاترین مرجع قانونی و معماری فنی سامانه است و بر تمامی فرآیندها، طراحی‌های بصری، توسعه کد، نگارش متون و تصمیم‌گیری‌های عامل هوش مصنوعی (Antigravity) اولویت قطعی دارد.

---

### اصل اول: تثبیت هویت و عنوان رسمی استاد (Scholar Identity)
۱. در تمامی صفحات، هدرها، فوترها، متادیتاها، تعاریف Swagger/OpenAPI، اسکیماهای سئو و پیام‌های سیستمی، نام استاد منحصراً و بدون کوچک‌ترین حذف، خلاصه یا تغییر باید به صورت زیر درج شود:
**«حجت الاسلام دکتر زنجیر زن حسینی»**
۲. هرگونه خلاصه‌سازی به عناوینی چون «دکتر زنجیرزن»، «استاد حسینی» یا پیشوندهای ناقص ممنوع و تخلف کیفی محسوب می‌شود.

---

### اصل دوم: مانیفست ضد اسلاپ و طراحی دست‌ساز انتشاراتی (Bespoke Editorial Press)
پلتفرم به عنوان یک آکادمی عقلانی و ناشر فاخر مونوگراف‌های فلسفی، باید شخصیتی اصیل، متمایز و مکتوب (مشابه *Stripe Press* و *Phaidon*) داشته باشد و از الگوهای لو رفته و کلیشه‌ای هوش مصنوعی مبرا باشد:
۱. **ممنوعیت هاله‌های نئونی بلور:** عدم استفاده از لکه‌های رنگی محو و افکت‌های ابری (`blur-3xl`, `bg-*-500/10`).
۲. **ممنوعیت متون گرادیانی بریده‌شده:** عدم استفاده از `bg-clip-text text-transparent bg-gradient-*`.
۳. **ممنوعیت نشانگرهای چشمک‌زن لوس:** عدم استفاده از نقاط سبز زننده و پالس‌های مصنوعی (`animate-pulse`).
۴. **ممنوعیت گرید‌های ۳ستونه کلیشه‌ای هوش مصنوعی:** عدم چیدن کارت‌های یکنواخت با آیکون‌های محبوس در مربع‌های رنگی بی‌خاصیت.
۵. **ممنوعیت جعبه‌های ۴تایی آمار شرکت‌های نوپا:** عدم استفاده از باکس‌های تکراری ارقام بدون بافت روایی.
۶. **الزام به هویت بصری فاخر:**
   - تایپوگرافی اصیل با خانواده فونت **دانا (`DanaFaNum`)** و فواصل خطوط دست‌ودلبازانه (`leading-[2.1]`).
   - پالت رنگی باوقار: ابسیدین عمیق مات (`#0C0D0E`, `#121316`)، چرم سوخته و مسگری (`#8A532B`, `#C58B43`)، و کاغذ کهن کاهی (`#FAF8F5`).
   - خطوط مرزی دقیق ۱ پیکسلی با ترنسپرنسی مهارشده (`border-stone-200 dark:border-neutral-800`).
   - چیدمان‌های نامتقارن، حواشی متنی آکادمیک (Margin Notes) و کلوفون رسمی کتاب.

### اصل سوم: استانداردهای نگارش فارسی اصیل (Persian Writing Quality)
طبق رهنمودهای مخزن مرجع `persian-writing`:
۱. **ممنوعیت کامل افعال فرسوده و اداری:**
   - عدم استفاده از «می‌باشد / می‌باشند» (منحصراً «است / هستند»).
   - عدم استفاده از فعل ربطی «می‌گردد / گردید» (منحصراً «می‌شود / شد»).
   - عدم استفاده از حشوهایی چون «سپری نمودن»، «به شمار می‌رود»، «محسوب می‌شود».
۲. **ممنوعیت کلیشه‌های رباتیک:** حذف «لازم به ذکر است»، «شایان ذکر است»، «نقش بسزایی»، «از اهمیت ویژه‌ای برخوردار است» و سه‌گانه‌های متقارن.
۳. **انضباط خط و رسم‌الخط:** رعایت الزامی نیم‌فاصله (ZWNJ)، استفاده از گیومه‌های فارسی (« »)، ارقام فارسی (۰۱۲۳۴۵۶۷۸۹)، و اصلاح حروف عربی ي/ك به ی/ک.
۴. **لحن:** رسمی، برهانی، زنده و انسانی، متناسب با کرسی درس خارج حوزه و پژوهشگاه حکمت معاصر.

### اصل چهارم: فیزیک حرکتی و تعاملات روان (Fluid Motion & 60fps Physics)
۱. انیمیشن‌ها باید بازتاب‌دهنده فیزیک طبیعی اشیاء مکتوب و لوکس باشند؛ از فنرهای نرم (`motion/spring`) برای جابه‌جایی تب‌ها (`layoutId`) و گشوده شدن ارگانیک کشوها و مودال‌ها استفاده می‌شود.
۲. پرش‌های ناگهانی یا انیمیشن‌های خطی مکانیکی ممنوع است.
۳. عملکرد رندرینگ باید بدون لگ و همواره بر روی ۶۰ فریم بر ثانیه پایدار بماند.

---

### اصل پنجم: مهندسی بک‌اند، امنیت و پایداری (Backend & Reliability)
۱. **حفاظت DRM از صوت:** تمامی استریم‌های صوتی و درس‌گفتارها باید دارای توکن امضاشده منقضی‌شونده باشند (`/api/v1/stream/token`).
۲. **معماری ORM:** استفاده از مدل‌های SQLAlchemy بدون کوئری‌های خام متنی.
۳. **پشتیبانی از Range Requests:** برای بارگذاری تکه‌تکه و بافر فوری صوت در حین جستجوی زمانی.
4. **مدیریت ساختاریافته خطاها:** استفاده از `AppException`.

---

### اصل ششم: سئو تکنیکال و استاندارد وب معنایی (Semantic Web & SEO)
۱. تولید پویای `sitemap.xml` و `robots.txt`.
۲. استقرار فایل `llms.txt` در ریشه جهت کرالرهای هوش مصنوعی مدرن.
۳. تزریق ساختار JSON-LD برای هویت استاد (`Person`)، درس‌گفتارها (`Course`) و کتاب‌های چاپی (`Book`).
