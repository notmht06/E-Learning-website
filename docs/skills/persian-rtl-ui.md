# Persian RTL UI Engineering Guide (راهنمای مهندسی رابط‌های راست‌چین)

این سند برگرفته از استانداردهای VibeFarsi برای طراحی و پیاده‌سازی رابط‌های کاربری اصیل فارسی در استک React و Tailwind CSS است.

## ۱. اصول بنیادین جهت‌گیری (Direction)
- **تنظیم در سطح ریشه سند:** ویژگی `<html lang="fa" dir="rtl">` منحصراً در ریشه سند تنظیم می‌شود؛ از قرار دادن صفت `dir="rtl"` روی تک‌تک تگ‌ها و کامپوننت‌ها پرهیز کنید.
- **انحصار در استفاده از ویژگی‌های منطقی (Logical CSS Properties):**
  - از کلاس‌های قدیمی و مطلق چپ/راست پرهیز شود.
  - مارجین: `ms-*` (Margin-Start) و `me-*` (Margin-End) به‌جای `ml-*` و `mr-*`.
  - پدینگ: `ps-*` (Padding-Start) و `pe-*` (Padding-End) به‌جای `pl-*` و `pr-*`.
  - موقعیت‌دهی: `start-*` و `end-*` به‌جای `left-*` و `right-*`.
  - ترازبندی متن: `text-start` و `text-end` به‌جای `text-left` و `text-right`.
  - حاشیه‌ها: `border-s` و `border-e` به‌جای `border-l` و `border-r`.
  - انحنای گوشه‌ها: `rounded-s-*` و `rounded-e-*` به‌جای `rounded-l-*` و `rounded-r-*`.
- **چیدمان Flex و Grid:** در جهت RTL، المان‌ها به صورت طبیعی از راست به چپ جریان می‌یابند؛ هرگز از `flex-row-reverse` برای «اصلاح» جهت استفاده نکنید.
- **فاصله‌گذاری فرزندان:** از کلاس `space-x-*` (که در برخی مرورگرها با RTL تداخل دارد) پرهیز کرده و همیشه از `gap-*` استفاده کنید.

## ۲. آیکون‌ها و المان‌های جهت‌دار
- آیکون‌های پیمایش به جلو (بعدی/ادامه/ارسال) در وب فارسی به سمت **چپ** اشاره دارند (`ChevronLeft`, `ArrowLeft`).
- آیکون‌های بازگشت (قبلی/انصراف) در وب فارسی به سمت **راست** اشاره دارند (`ChevronRight`, `ArrowRight`).
- آیکون‌های بدون جهت (ذره‌بین جستجو، سطل زباله، سبد خرید، تقویم) بدون تغییر جهت باقی می‌مانند.

## ۳. فیلدهای داده‌های فنی لاتین در صفحه فارسی
فیلدهای ذیل باید حتی درون صفحات راست‌چین، با ویژگی `dir="ltr"` به صورت چپ‌به‌راست نمایش داده شوند:
- شماره تلفن همراه و تلفن ثابت
- نشانی رایانامه (ایمیل)
- شماره شبا (IBAN) و شماره کارت‌های ۱۶ رقمی بانکی
- کدهای اعتبارسنجی (OTP)
- آدرس‌های اینترنتی (URL) و قطعه‌کدهای برنامه‌نویسی

## ۴. لودینگ و اسکلت بدون پرش (Zero CLS)
- هرگز در صفحات اصلی از اسپینر چرخان خشک بدون اسکلت محتوا استفاده نکنید.
- قبل از رسیدن داده‌ها، فضا را با کامپوننت `Skeleton` هم‌اندازه با ساختار نهایی رزرو کنید.
- برای جابجایی اسکلت به محتوای واقعی از `SkeletonReveal` استفاده نمایید تا کمترین پرش چیدمان (Cumulative Layout Shift = 0) پدید آید.
